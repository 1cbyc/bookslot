# BookSlot

BookSlot is an appointment booking and reminder system for service businesses.

## Problem

Salons, clinics, barbers, coaches, photographers, and consultants often manage bookings through scattered chat messages. That creates missed appointments, double bookings, and manual reminder work.

## Solution

BookSlot gives customers a simple booking flow and gives the business an admin view for appointments, reminders, and status updates.

## Planned Features

- Service selection
- Appointment booking form
- Admin appointment dashboard
- Customer confirmation message
- Business owner notification
- Reminder before appointment
- Cancel or reschedule flow
- Calendar integration notes

## Stack

- Next.js
- FastAPI
- PostgreSQL
- Redis
- Docker Compose
- Telegram Bot API
- Calendar integration

## Business Value

- Fewer missed appointments
- Less manual scheduling
- Better customer communication
- Clear daily appointment view

## Portfolio Notes

This project is designed to be easy to adapt for salons, clinics, schools, coaches, and local service providers.
